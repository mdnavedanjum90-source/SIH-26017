check_circle MANDATORY SYSTEM DIRECTIVES (DO)
  • done One accent moment per card: Reserve Electric Teal (#2DD4BF) exclusively for primary sovereign calls-to-action or active state selection bars.
  • done Dual-encoded risk vectors: Always pair statutory risk colors with both a text label and an unambiguous icon glyph (WCAG AAA requirement).

cancel PROHIBITED ANTI-PATTERNS (DON'T)
  • close No isolated color indicators: Never use color alone without textual accompaniment to signal RFCTLARR Section 25 statutory lapse risk.
  • close No generic SaaS aesthetics: Absolutely no purple/indigo gradient blobs, floating marketing heroes, or playful rounded toy button styles.
  • close No lorem ipsum filler: Never display dummy text; every placeholder must reference authentic RFCTLARR 2013 legal sections and cadastral terms.
